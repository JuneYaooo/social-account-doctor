# commerce-metrics — 带货视频核心指标与评分标准

> 本文件是 SKILL.md commerce 模式（§1B）的指标参考。
> 定义带货视频特有的 ECPM、转化率、商品点击率等指标，以及内容力/流量点/转化点的评分标准。

---

## 0. 数据来源声明

本文件所有阈值均为**行业经验值**（非平台官方），主要来源：

- 抖音电商学习中心 — [school.jinritemai.com](https://school.jinritemai.com/doudian/web/home)
- 蝉妈妈 / 飞瓜数据 / 卡思数据 — 第三方直播和短视频电商数据分析平台
- 巨量千川 — 广告投放和素材数据
- 跃狐未来达人商业化社群课程资料

⚠️ 所有数字用作方向判断，**不是平台官方规则**。具体阈值因品类波动较大（美妆天然转化高、家电天然转化低），用区间不要用绝对值。

📅 **数据采集日期：2026-08 / 建议复核周期：6 个月**。

### 0.1 数据输入要求

commerce 不自动拉取任何平台或电商后台指标。只有用户提供后台导出 JSON、CSV 或清晰截图时才计算实际指标。

| 指标 | 用户需要提供 |
|---|---|
| 播放、点赞、评论、分享 | 创作者后台导出或用户整理的 JSON |
| 5s/整体完播率 | 创作者后台截图或导出 |
| 商品点击率、购物车打开率 | 抖店/投放后台截图或导出 |
| 下单率、成交转化率、GPM | 商家后台截图或导出 |
| 佣金与实际收入 | 用户自己的结算数据 |

没有对应后台数据时，只做视频内容结构评分，不用公开互动或行业均值估算转化结果。

## 1. 带货视频核心指标

### 1.1 内容漏斗（内容质量）

| 指标 | 计算 | 偏低 | 合格 | 优秀 | 说明 |
|---|---|---|---|---|---|
| 5s 完播率 | 看到 5s / 曝光 | < 35% | 35-50% | > 50% | 带货视频前 5s 必须有利益点或痛点 |
| 整体完播率 (≤30s) | 完整看完 / 曝光 | < 25% | 25-40% | > 40% | 商品露出前不能塌 |
| 整体完播率 (30-60s) | 完整看完 / 曝光 | < 15% | 15-28% | > 28% | — |

### 1.2 转化漏斗（电商特有）

| 指标 | 计算 | 偏低 | 合格 | 优秀 | 说明 |
|---|---|---|---|---|---|
| 商品点击率 | 点商品卡 / 曝光 | < 0.5% | 0.5-2% | > 2% | 商品露出时机和方式的直接影响 |
| 下单率 | 下单 / 商品点击 | < 1% | 1-3% | > 3% | 价格/利益点/信任感的综合结果 |
| 成交转化率 | 成交 / 下单 | < 30% | 30-60% | > 60% | 受价格/优惠/履约影响，内容可控度低 |
| 购物车打开率 | 打开购物车 / 曝光 | < 0.3% | 0.3-1% | > 1% | 抖音/快手挂车视频 |

### 1.3 综合效率

| 指标 | 计算 | 说明 |
|---|---|---|
| GPM（千次曝光成交额） | 成交额 / 曝光 × 1000 | 内容+商品综合效率，越高越好 |
| ECPM（千次曝光收益） | 预估收益 / 曝光 × 1000 | 含佣金，达人视角的核心指标 |
| 内容互动率 | (赞+评+藏+转) / 曝光 | 带货视频通常低于非带货（1-3%），因为有商品卡分流 |

## 2. 内容力 / 流量点 / 转化点 评分标准

### 2.1 内容力（Content Power）— 前 3 秒能否留住人

| 分数 | 描述 | 典型表现 |
|---|---|---|
| 10 | 前 3 秒三合一：人群锁定 + 利益承诺 + 好奇缺口 | "30岁后代谢变慢？这个方法我用了3周，腰围少了6cm" |
| 7-9 | 命中两个：有人群 + 利益 OR 利益 + 好奇 | "这款洗面奶居然把氨基酸做到了这个价格" |
| 4-6 | 命中一个：有利益但没有人群锚定 | "这个真的很好用" |
| 1-3 | 无钩子：自我介绍/品牌介绍/静止画面 | "大家好今天给大家推荐一款..." |

### 2.2 流量点（Traffic Trigger）— 能否引发互动和转发

| 分数 | 描述 | 典型表现 |
|---|---|---|
| 10 | 有明确的槽点/争议点/身份认同触发 | "用过的姐妹来说说是不是这样？反正我先说..." |
| 7-9 | 有互动钩子但不够自然 | 结尾"评论扣1"但没有给足够的理由 |
| 4-6 | 有信息价值但缺乏分享动机 | 纯干货但没情绪，没人会转发 |
| 1-3 | 无任何互动设计 | 纯展示，结尾无 CTA |

### 2.3 转化点（Conversion Trigger）— 能否推动下单

| 分数 | 描述 | 典型表现 |
|---|---|---|
| 10 | 痛点→证明→价格→CTA 完整链路，每步有证据 | 展示使用前后 → 对比成分表 → 报价格和赠品 → "库存不多" |
| 7-9 | 链路完整但缺少证明动作 | 说了好处但没展示证据 |
| 4-6 | 有产品展示但无明确转化引导 | 商品出现了但没说在哪买/为什么现在买 |
| 1-3 | 商品出现时机差/方式生硬 | 生硬插入广告，跟前后内容脱节 |

## 3. 商品露出方式评分

| 方式 | 自然度 | 转化力 | 适用品类 |
|---|---|---|---|
| 使用过程自然展示 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 美妆/食品/日用品 |
| 对比实验/测试 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 清洁/护肤/家电 |
| 开箱/拆包 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 3C/潮玩/服饰 |
| 口播提及+画面展示 | ⭐⭐⭐ | ⭐⭐⭐ | 知识付费/服务 |
| 手持展示+口播 | ⭐⭐⭐ | ⭐⭐⭐⭐ | 好物推荐通用 |
| 纯商品卡/图文轮播 | ⭐⭐ | ⭐⭐ | ❌ 千川低质素材风险 |

## 4. 利益点顺序最佳实践

### 黄金结构（已验证的带货视频结构）

```
[0-3s]   痛点/人群锁定 → "你是不是也..."
[3-8s]   产品引入 → "直到我发现了这个..."
[8-15s]  利益点 1 + 证明动作 → 使用前后/对比/成分展示
[15-22s] 利益点 2 + 场景扩展 → 不同使用场景
[22-28s] 价格/赠品/活动 → "现在买还送..."
[28-30s] CTA → "链接在评论区/主页"
```

### 常见错误

| 错误 | 后果 | 修法 |
|---|---|---|
| 开头讲品牌故事 | 前 3s 没钩子 → 划走 | 品牌信息后置到中间 |
| 利益点堆砌无证明 | 用户不信 → 不转化 | 每个利益点配一个画面证据 |
| 商品出现太晚（>15s） | 用户还不知道在卖什么 | 8s 内必须出现商品 |
| CTA 太弱/没有 | 看完不知道去哪买 | 最后 5s 必须明确 CTA |
| 价格放在最前面 | 还没建立价值就谈价格 = 劝退 | 先建立价值感再报价格 |

## 6. 千川低质素材常见特征（需在 review/adapt 中规避）

来源：飞书课程《低质素材避坑指南》+ 抖音电商学习中心。

| 特征 | 判定 | 规避方法 |
|---|---|---|
| 商品堆砌式累加 | 一个视频塞 5+ 个不同品 | 一条视频只讲 1 个品 |
| 品牌/款式/颜色/形状不一致 | 视频展示 A 款，链接是 B 款 | review 时检查商品卡一致性 |
| 口播/画面/详情页规格不一致 | 口播说 500ml，详情页是 300ml | adapt 强制读取 SKU |
| 卖惨/演戏炒作/清仓话术 | "老板跑路了""血亏清仓" | adapt 禁用表达清单 |
| 红包/价格/赠品条件不完整 | "买一送一"但没说是送同款还是小样 | adapt 必须标注完整条件 |
| 图片轮播/大字报/高饱和度 | 无实拍，纯图文拼接 | 分镜必须含实拍建议 |
| 黑边/遮挡/水印/模糊变形 | 搬运素材特征 | review 标注素材来源和授权风险 |
| 商品主体不明确 | 配料表/尺码表替代商品主体 | 分镜提示明确商品在画面中的位置和大小 |

  "target_audience": [],
  "pain_points": [],

  "buying_points": [],
  "proof_actions": [],
  "usable_copy": [],
