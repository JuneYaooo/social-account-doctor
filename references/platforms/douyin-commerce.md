## 1. 抖音电商内容核心规则

### 1.1 商品三一致（T0 级 — 不做就违规）

抖音电商最基础的规则：视频中展示的商品必须与商品详情页一致。

| 检查项 | 要求 | 不一致的后果 |
|---|---|---|
| 品牌一致 | 视频展示品牌 = 详情页品牌 | 下架 + 扣分 |
| 款式一致 | 视频展示款式 = 链接对应 SKU | 退货率飙升 + 差评 |
| 颜色一致 | 视频展示颜色 = 链接选中颜色 | 纠纷 + 平台处罚 |
| 规格一致 | 口播/字幕的规格 = SKU 实际规格 | 虚假宣传 |
| 价格一致 | 视频口播价格 = 链接实际价格 | 价格欺诈 |
| 赠品一致 | 承诺的赠品 = 实际发货的赠品 | 违约 + 差评 |

### 1.2 商品卡规范

| 规范 | 要求 |
|---|---|
| 商品主图 | 清晰、白底或干净背景、商品占画面 60%+ |
| 商品标题 | 品牌+核心属性+规格，不用夸张词 |
| 价格标注 | 明确标价，不能用"低价""惊爆价"替代实际价格 |
| SKU 命名 | 规格差异清晰，不用误导性命名 |
| 详情页 | 实拍为主，不得盗用他人图片 |

## 2. 千川低质素材特征（⚠️ 课程案例，非官方规则原文）

以下特征来自飞书课程《低质素材避坑指南》的案例总结。在 commerce-review 和 commerce-adapt 中需要规避。

### 2.1 画面质量类

| 特征 | 说明 | 规避方法 |
|---|---|---|
| 商品堆砌式累加 | 一个视频展示 5+ 个不同商品 | 一条视频只讲 1 个品 |
| 图片轮播 | 非实拍视频，多张图片拼接轮播 | 必须有实拍镜头 |
| 大字报 | 整屏大字覆盖，商品看不清 | 大字只能做辅助，不能遮挡商品 |
| 高饱和度配色 | 刺眼的红/黄/绿大面积使用 | 调色自然，用实拍原色 |
| 黑边 | 视频有明显黑边未裁切 | 全屏 9:16，无黑边 |
| 遮挡 | 水印/logo/贴纸遮挡商品 | 移除所有遮挡物 |
| 模糊变形 | 分辨率低/拉伸变形 | 1080P 以上，比例正确 |
| 商品主体不明确 | 配料表/尺码表/文字替代商品 | 商品实物必须在画面中占据主体位置 |

### 2.2 内容质量类

| 特征 | 说明 | 规避方法 |
|---|---|---|
| 品牌/款式/颜色不一致 | 视频展示的跟链接是不同款 | 拍摄前确认 SKU，使用对应款式 |
| 口播/画面/详情页规格不一致 | 三个地方说了三个不同的规格 | adapt 时三方核对 |
| 卖惨/演戏炒作 | "老板跑路""血亏清仓""家里出事" | 禁用表达清单 |
| 清仓话术 | "最后一天""马上涨价""仅剩 N 件" | 如属实可用，虚假则违规 |
| 红包/价格/赠品条件不完整 | 说了送但不说送什么/送多少 | 完整写清条件 |

### 2.3 不适内容类

| 特征 | 说明 |
|---|---|
| 污垢 | 故意展示污垢/恶心画面吸引眼球 |
| 血腥 | 包含血腥画面（即使是演示效果） |
| 危险动作 | 可能被模仿的危险行为 |
| 恶俗 | 低俗/恶搞/不雅内容 |
| 引人不适的动物 | 蛇/蜘蛛/蟑螂等引起恐惧的画面 |

## 3. 禁用表达清单

### 3.1 绝对化用语（广告法禁用的极限词）

| 类别 | 禁用词示例 | 替代表达 |
|---|---|---|
| 极限词 | 最/第一/独家/唯一/全网/全国/首发 | "很少见的""我用过最好的之一" |
| 权威背书 | 国家推荐/政府认证/央视上榜 | 出示具体证书编号，否则删除 |
| 功效承诺 | 保证有效/100%/一定/绝对/根治/治愈 | "帮助改善""用户反馈""我个人的体验是" |
| 时效承诺 | N 天见效/N 天瘦 X 斤 | 不承诺具体结果，展示真实使用过程 |
| 价格误导 | 全网最低/亏本/不要钱/免费 | 标实际价格，限时优惠标注截止时间 |

### 3.2 行业特殊限制

| 行业 | 禁用表达 | 允许表达 |
|---|---|---|
| 食品 | 治疗/预防疾病/药用/药效 | 营养/美味/饱腹/成分天然 |
| 化妆品 | 修复/治疗/消炎/祛痘（暗示医疗效果） | 保湿/清洁/修饰/帮助改善 |
| 保健品 | 治病/替代药物/疗效/治愈 | 保健/辅助/补充（需有蓝帽子资质） |
| 母婴 | 最安全/零添加/医生推荐 | 成分公开/检测报告/适合 X 月+ |
| 宠物食品 | 治疗/药用/保证健康 | 营养均衡/适口性好/毛发改善 |
| 金融/保险 | 保本/稳赚/无风险/高收益 | 历史数据/风险提示 |

### 3.3 价格与促销禁用表达

| 禁用 | 允许（如属实） |
|---|---|
| "全网最低价" | "当前活动价 XX 元"（标注截止时间） |
| "亏本卖" | "优惠活动"（不强调亏本） |
| "最后一天"（虚假紧迫感） | 如属实，标注具体日期"活动截至 X 月 X 日" |
| "不要钱" | 不可能，不要说 |
| "原价 999 现价 99"（虚构原价） | 划线价需有真实成交记录支撑 |

## 4. 抖音电商视频技术规范

| 规范项 | 要求 |
|---|---|
| 视频比例 | 9:16（竖屏全屏）或 16:9（横屏 — 不推荐带货） |
| 分辨率 | ≥ 1080P |
| 时长 | 建议 15-60s（带货视频不建议超过 90s） |
| 字幕 | 适配静音播放，关键信息（价格/规格/利益点）必须上字幕 |
| BGM | 可用平台热门音乐（有助于推荐），不盖过口播 |
| 封面 | 首帧即封面，建议含商品+利益点大字 |
| 购物车 | 视频发布时挂小黄车，确保商品链接有效 |

## 5. 带货视频审核清单（发布前自查）

### 内容层

- [ ] 前 3 秒有钩子（痛点/好奇/人群锁定）
- [ ] 商品 8s 内出现
- [ ] 每个利益点有画面证据
- [ ] CTA 明确且自然
- [ ] 没有念稿感

### 合规层

- [ ] 视频展示商品 = 商品链接对应 SKU（品牌/款式/颜色/规格一致）
- [ ] 口播价格 = 链接实际价格
- [ ] 赠品/优惠条件完整说明
- [ ] 无绝对化用语（最/第一/独家/根治/保证）
- [ ] 无功效承诺（如涉及功效，有资质证据）
- [ ] 无卖惨/演戏/清仓话术
- [ ] 素材来源有授权（非搬运）

### 技术层

- [ ] 9:16 竖屏，≥ 1080P
- [ ] 无黑边/水印/模糊变形
- [ ] 字幕完整，关键信息有大字
- [ ] 首帧 = 封面（有钩子）
- [ ] 商品链接有效

## 6. 违规分级

| 级别 | 定义 | 示例 | 处理 |
|---|---|---|---|
| Blocker | 立即违规，发布即处罚 | 虚假宣传/三不一致/无资质卖特殊品类 | 不发，修改后重新审核 |
| High | 高概率违规或高概率客诉 | 赠品条件不完整/功效暗示/素材来源不明 | 不发，修改后重新审核 |
| Medium | 可能被平台标记但不会立即处罚 | 标题党/稍夸张的表达/字幕错别字 | 建议修改，是否发布由达人决定 |
| Low | 优化建议 | 画面构图可优化/BGM 可换更热门的 | 可发，下次改进 |
