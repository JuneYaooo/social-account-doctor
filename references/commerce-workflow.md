# commerce-workflow — 证据驱动的带货素材工作流

> commerce 复用项目核心的账号诊断、视频链接解析、`find` 对标搜索和 `crack` 多模态拆解。商品事实仍只来自用户上传材料；不抓在线商品页，不做选品与趋势监控。

## 1. 能力边界

| 输入 | 可以做 | 不可以做 |
|---|---|---|
| 带货账号主页链接 | 三层账号诊断、同赛道账号对标、电商内容差距 | 没有后台数据时推断真实转化漏斗 |
| 平台带货视频链接或本地视频 | 解析/下载后做多模态拆解，并与 3-5 条同类视频比较 | 媒体获取失败时假装看过画面 |
| 详情页/SKU/价格/资质截图或文件 | 构建有来源的 ProductFactCard | 自动确认页面当前仍有效 |
| ProductFactCard + 账号定位/目标人群 | 生成 15s/30s/60s 口播、分镜、CTA | 使用未核验功效、价格、赠品或库存 |
| 用户导出的后台指标 JSON | 按指定账号历史样本归一化 | 自动登录后台、自动拉取投放数据 |

以下请求直接说明不支持，不生成替代结果：

- 只给商品链接并要求自动分析商品。
- 只给商品链接并要求把它当成视频链接或商品事实证据。
- 选品 Top10、趋势雷达、佣金排行。
- 根据公开视频互动推断真实销量、GMV、点击率或转化率。

## 2. 路由

### commerce-diagnostic

输入：带货账号主页链接；平台。后台指标和用户指定对标可选。

1. 复用通用 diagnostic 的 Layer 1-3，不单独发明电商诊断流程。
2. 用 `find` 筛选 3-5 个同平台、同品类、同内容形态且体量可比的账号。
3. 比较我方 top 3 + bottom 3 与对标 top 3 的内容，不只比较粉丝量和互动总数。
4. 通用六维之外，增加商品露出、利益点、证明动作、信任点、CTA、商品一致性和合规风险。
5. 没有后台指标时不判断真实点击/成交漏斗；没有有效对标时标记“部分诊断”。

### commerce-review

输入：平台带货视频链接或本地视频；账号定位。商品资料、后台指标和用户指定对标可选。

1. 链接输入先复用通用 `crack` 的分享链接解析、详情和媒体下载工具；下载到临时目录后运行 `scripts/analyze_video.py`。连续 3 次失败则要求本地文件。
2. 输出视觉/文字/口播/剧情 4 维钩子，以及商品露出、利益点顺序、转化结构、商品卡一致性、复刻风险。
3. 用户只要求客观拆解时，可在完整多模态分析后交付单条 `crack`，但不能把它称为账号诊断或效果诊断。
4. 用户询问原因、差距或改法时，提取内容本质并复用 `find` 搜索，经过多模态过滤后保留 3-5 条同品类、同载体、同人群的对标视频。
5. 诊断型请求横向比较前 3 秒、首次商品露出、利益点、证明动作、信任点、CTA、评论反馈和复刻成本。
6. 每个差距结论引用目标时间戳和对标证据；搜索失败时标记“部分（缺对标层）”，不得伪造对标。
7. 只有提供商品资料时才判断商品卡一致性；只有提供后台数据时才计算实际指标。

平台边界：抖音、小红书、快手和 B 站按各自作品链接解析；视频号没有普通可复制作品 URL，改走账号名/关键词搜索或本地文件。`tikhub --health`/`list` 成功不能替代真实业务调用，链接解析和对标搜索必须分别做一次冒烟调用。

### commerce-adapt

输入：商品名称；至少一份商品证据；账号定位；目标人群。本地参考视频可选。

1. 逐份解析详情截图、SKU 表、资质文件和品牌资料。
2. 构建 ProductFactCard；每条事实记录文件名与页码/截图/行号。
3. 将材料未覆盖或互相冲突的字段放入 `pending_verification`。
4. 只用 `confidence=confirmed` 的事实生成口播和分镜。
5. 用 `scripts/build_commerce_package.py` 校验并生成 JSON；校验失败时不交付。

## 3. ProductFactCard 2.0

唯一契约定义在 `references/commerce-metrics.md`。Markdown 至少包含：

```markdown
# 商品事实卡

商品名称: 示例商品
商品链接: https://example.com/item/123  # 可选，仅记录
资料确认时间: 2026-08-13T00:00:00Z

## 商品事实
- 规格为 30ml，来源：sku.png 第 1 行
- 含透明质酸钠，来源：ingredient.pdf 第 2 页

## SKU
- 30ml/瓶 | 99.00 | 用户截图显示有货

## 待核验项
- 活动截止时间未提供
```

来源为空的事实不能进入确定性脚本。商品链接不是必填项，也不能替代证据。

## 4. 交付文件

```text
reports/
  commerce-diagnostic-{YYYYMMDD-HHMM}.md
  commerce-review-{YYYYMMDD-HHMM}.md
  product-fact-{YYYYMMDD-HHMM}.md
  commerce-adapt-{YYYYMMDD-HHMM}.md
  commerce-package-{YYYYMMDD-HHMM}.json
```

没有完成事实卡或视频分析时不写半成品报告。

## 5. 错误处理

| 场景 | 处理 |
|---|---|
| 只有商品链接 | 要求上传详情页、SKU、价格活动和资质材料 |
| 视频链接解析/媒体下载连续失败 | 明示失败步骤，要求上传本地视频文件 |
| 对标搜索连续失败或不足 3 条 | 标记部分分析，请用户补 3-5 条对标链接 |
| 商品材料互相冲突 | 列出冲突，停止脚本生成 |
| 商品事实没有来源 | 放入待核验，不写入确定性口播 |
| 高风险品类缺资质 | 停止生成发布稿，只输出缺失资质清单 |
| 后台指标缺失 | 只做内容结构审查，不估算转化指标 |
