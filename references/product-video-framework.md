# product-video-framework — 商品展示配方与镜头语言

> 本文件是 SKILL.md commerce 模式（§1B）的视频制作参考。
> 定义带货视频的 5 种商品展示配方、镜头语言、商品露出时机和方式的最佳实践。

---

## 0. 五种带货视频配方

### 配方 1：问题解决型（最通用，适合大多数品类）

```
结构：[痛点场景] → [产品引入] → [使用过程] → [效果展示] → [价格/CTA]

适用品类：美妆护肤、清洁用品、日用百货、健康食品
推荐时长：30-45s
核心指标：5s 完播率 + 商品点击率

分镜模板：
  镜1 (0-3s)：痛点场景特写（如：油腻的厨房/暗沉的皮肤）
  镜2 (3-8s)：产品登场（手持展示/开箱/倒出产品）
  镜3 (8-18s)：使用过程（涂抹/清洁/使用中 — 加速或关键步骤慢放）
  镜4 (18-25s)：效果对比（使用前/后，用画面说而不是用嘴说）
  镜5 (25-30s)：价格/赠品/活动 + CTA
```

### 配方 2：对比评测型（建立信任，适合功能型产品）

```
结构：[竞品痛点] → [本品引入] → [对比实验] → [数据/结果] → [价格锚点]

适用品类：家电、3C、清洁用品、护肤品（成分对比）
推荐时长：40-60s
核心指标：完播率 + 信任感（评论区的"真的假的"→"买了"）

分镜模板：
  镜1 (0-3s)：实验准备（两杯水/两块布/两个产品并排）
  镜2 (3-10s)：对比实验过程（同时操作，画面分屏或左右对比）
  镜3 (10-20s)：结果特写（差距要肉眼可见，不要靠嘴说）
  镜4 (20-30s)：原理解释（为什么有这个差距 — 成分/材质/技术）
  镜5 (30-40s)：价格锚点（"市面上同效果的卖XX，这个只要XX"）
```

### 配方 3：场景种草型（生活方式植入，适合非功能型产品）

```
结构：[美好场景] → [产品自然出现] → [使用瞬间] → [情绪升华] → [引导]

适用品类：服饰、香薰、家居、零食、饮品
推荐时长：15-25s
核心指标：完播率 + 收藏率（用户收藏=想买）

分镜模板：
  镜1 (0-2s)：氛围感场景（晨光/雨天/独处/聚会 — 情绪先行）
  镜2 (2-6s)：产品自然融入场景（桌上的杯子/身上的衣服/手里的零食）
  镜3 (6-12s)：使用瞬间特写（喝一口/穿身上转一圈/撕开包装的声音）
  镜4 (12-18s)：情绪升华（满足的表情/放松的氛围/开心的反应）
  镜5 (18-22s)：引导（"同款在主页/链接在评论区" — CTA 要轻，不破坏氛围）
```

### 配方 4：开箱/试用型（真实感，适合新奇特产品）

```
结构：[好奇心引入] → [开箱过程] → [第一印象] → [使用体验] → [总结推荐]

适用品类：3C 数码、潮玩盲盒、新奇小家电、美妆新品
推荐时长：30-50s
核心指标：5s 完播率（好奇心驱动）+ 互动率（"值不值"引发评论）

分镜模板：
  镜1 (0-3s)：包装特写 + 悬念（"这个东西据说能..."/"最近超火的那个..."）
  镜2 (3-12s)：开箱过程（撕包装/打开盒子 — 加速但保留声音）
  镜3 (12-22s)：产品第一印象（外观/手感/大小对比）
  镜4 (22-35s)：实际使用（第一次用的真实反应 — 不要演）
  镜5 (35-45s)：总结 + 是否推荐 + 适合什么人
```

### 配方 5：剧情带货型（内容即广告，适合有表演能力的达人）

```
结构：[剧情冲突] → [产品介入] → [冲突解决] → [自然转化]

适用品类：通用（但需要强表演/编剧能力）
推荐时长：40-90s
核心指标：完播率 + 分享率（剧情有传播性）
风险：容易"剧情太好看没人买"或"广告太硬没人看"

分镜模板：
  镜1 (0-5s)：剧情冲突建立（人物+场景+问题）
  镜2 (5-15s)：冲突升级（问题变严重/尴尬）
  镜3 (15-25s)：产品介入（自然出现在剧情中，不是生硬插入）
  镜4 (25-35s)：使用产品 → 冲突解决/改善
  镜5 (35-45s)：结果 + 呼应开头 + 自然引导（"你也可以试试"）
```

## 1. 商品露出时机与方式

### 露出时机

| 视频时长 | 商品首次露出 | 原因 |
|---|---|---|
| 15s | 3-5s | 前 3s 建痛点/好奇，接着出商品 |
| 30s | 5-8s | 足够的铺垫 + 不让用户等太久 |
| 60s | 8-15s | 可以多铺垫，但不能超过 15s |
| 90s+ | 10-20s | 剧情型可以晚，但要有前兆暗示 |

### 露出方式对比

| 方式 | 适合配方 | 优点 | 缺点 | 评分 |
|---|---|---|---|---|
| 手持展示 | 1/2/4 | 直观、真实、成本低 | 手抖/光线差降低质感 | ⭐⭐⭐⭐ |
| 桌面/台面展示 | 1/2/4 | 稳定、可控制光线 | 缺少生活感 | ⭐⭐⭐ |
| 使用过程自然露出 | 1/3 | 最自然、转化率高 | 需要设计场景 | ⭐⭐⭐⭐⭐ |
| 开箱过程 | 4 | 好奇心驱动、互动率高 | 只能用一次 | ⭐⭐⭐⭐ |
| 对比实验 | 2 | 信任感最强 | 准备成本高、某些品类没法做对比 | ⭐⭐⭐⭐⭐ |
| 口播+画面切 | 1/5 | 灵活 | 容易变成"配音+PPT"的低质素材 | ⭐⭐ |
| 剧情中自然出现 | 5 | 内容价值高、传播性强 | 编剧门槛高、容易喧宾夺主 | ⭐⭐⭐⭐ |

## 2. 镜头语言速查

### 景别

| 景别 | 用途 | 带货场景 |
|---|---|---|
| 大特写 | 强调细节 | 成分表/质地/使用前后局部对比 |
| 特写 | 突出主体 | 产品外观/logo/包装质感 |
| 近景 | 展示使用 | 涂抹护肤品/切菜/操作小家电 |
| 中景 | 展示场景 | 人物+产品关系/使用环境 |
| 全景 | 展示效果 | 全身穿搭/房间改造前后 |

### 运镜

| 运镜 | 用途 | 带货场景 |
|---|---|---|
| 固定镜头 | 稳定展示 | 桌面展示/对比实验 |
| 推镜头（靠近） | 引导注意力 | 从全景推到产品特写 |
| 拉镜头（远离） | 揭示整体 | 从产品特写拉到使用场景 |
| 摇镜头 | 展示全貌 | 扫过一排产品/展示房间 |
| 跟镜头 | 跟踪动作 | 跟手部动作（倒/抹/搅拌） |

### 转场

| 转场 | 用途 | 带货场景 |
|---|---|---|
| 硬切 | 节奏变化 | 大多数带货视频的默认转场 |
| 匹配剪辑 | 流畅过渡 | 产品从手上→桌上的连续感 |
| 缩放转场 | 强调 | 从产品→成分表的放大 |
| 声音先入 | 引导期待 | 下一个镜头的使用声音提前 0.5s |

## 3. 不同时长的内容密度

| 时长 | 核心利益点数量 | 镜头数（建议） | 口播字数 |
|---|---|---|---|
| 15s | 1 个 | 3-5 个 | 40-60 字 |
| 30s | 1-2 个 | 5-8 个 | 80-120 字 |
| 60s | 2-3 个 | 8-15 个 | 150-220 字 |
| 90s | 3-4 个 | 12-20 个 | 220-320 字 |

## 4. 声音设计

| 元素 | 用途 | 注意 |
|---|---|---|
| 口播 | 信息传递主力 | 自然语速 180-220 字/分钟，不要念稿感 |
| 环境音 | 增强真实感 | 倒水声/撕包装声/使用声 — 保留，不要全压掉 |
| BGM | 情绪引导 | 轻量背景，不要盖过口播；选平台热门音乐有助于推荐 |
| 音效 | 强调动作 | 对比实验的"叮"/价格出现的"叮" — 1-2 次即可，多了像电视购物 |
| 字幕 | 信息补充 | 关键利益点/价格/规格用大字幕强化；适配静音播放场景（50%+ 用户静音刷视频） |

## 5. 电商商品展示配方（新增，配合 capsule-cinema）

当 ScriptPackage 交给 capsule-cinema 进行视频生产时，需要补充以下电商专属信息：

```json
{
  "product_showcase": {
    "recipe": "配方1-5的编号",
    "product_appearance_timing": "商品首次出现的秒数",
    "product_display_method": "手持/桌面/使用中/对比",
    "key_visual_moments": [
      {"time": "0-3s", "shot": "痛点场景特写", "notes": "油腻的厨房台面"},
      {"time": "3-8s", "shot": "产品登场", "notes": "手持产品，logo 朝向镜头"},
      {"time": "8-18s", "shot": "使用过程", "notes": "加速 2x，关键步骤 0.5x 慢放"},
      {"time": "18-25s", "shot": "效果对比", "notes": "左右分屏，使用前/后"}
    ],
    "text_overlays": [
      {"time": "0-2s", "text": "痛点大字", "position": "center"},
      {"time": "3-8s", "text": "产品名+核心卖点", "position": "bottom-third"},
      {"time": "22-25s", "text": "价格+赠品信息", "position": "bottom-third"}
    ],
    "compliance_checks": [
      "商品展示与详情页一致",
      "价格/规格/赠品信息完整",
      "无功效承诺/绝对化用语",
      "素材来源有授权"
    ]
  }
}
```

## 6. 常见带货视频翻车清单

| 翻车点 | 原因 | 预防 |
|---|---|---|
| 视频展示 A 款，链接是 B 款 | SKU 没核对 | adapt 前强制核对 SKU |
| 口播说"买一送一"，实际是买大送小 | 赠品条件没说完整 | 文案里写完整：买 X 送 Y（同款/小样/试用装） |
| 说"全网最低"但没有证据 | 绝对化用语违规 | 禁用表达清单前置 |
| 视频用了他人的素材 | 版权风险 | crack 标注素材来源和授权状态 |
| 功效说得太绝对 | 广告法风险 | "改善"替代"治愈"，"帮助"替代"保证" |
| 价格已过期 | 活动结束了视频还在跑 | 价格标记有效期，提醒用户确认 |
| 视频挂了但商品下架了 | 库存/链接失效 | 发布前检查链接可访问 |
